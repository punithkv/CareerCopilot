# CareerCopilot frontend redesign

This package contains the updated frontend source code.

## What changed
- Replaced `src/App.jsx` with a responsive application shell.
- Added `src/careercopilot-redesign.css` for the new dark/light theme, sidebar, topbar, responsive navigation, and shared component styling.
- Kept existing component and service files intact.

## Run
From this frontend folder:
```powershell
npm install
npm run dev
```
The backend and local Ollama service must also be running for AI-powered features.
